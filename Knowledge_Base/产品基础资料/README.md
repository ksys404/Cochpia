## 原始资料

- `原始PDF/`：从用户 Downloads 目录复制的原始文件，保持原文件名和内容不变。
- `抽取文本/`：使用 pypdf 从 PDF 文本层提取的文本。
- `PDF页面预览/`：用于视觉核验的临时页面预览，不作为原始资料。

# Cochpia 模型配置与前端交互

## 配置边界

- 模型目录由服务端本地维护，包含供应商、协议、推荐模型和生产场景注释。
- API Key 只从服务端环境变量读取，不进入浏览器，不写入 `server/data/state.json`。
- `ready=true` 只表示配置项完整，不代表真实云端调用成功。
- 当前配置按服务实例读取，模型选择按会话保存。

## API

### `GET /api/models`

返回 `defaultProvider` 和 `providers`。供应商字段包括 `provider`、`label`、`protocol`、`model`、`suggestedModels`、`useCases`、`ready`、`error`。

### `GET /api/sessions/:id/model`

读取会话当前的 `modelProvider`、`modelName` 和配置状态。

### `PATCH /api/sessions/:id/model`

请求体：

```json
{ "provider": "mock", "model": "mock" }
```

服务端校验供应商、模型和环境变量。无效选择不会保存；未配置供应商返回 `MODEL_NOT_CONFIGURED`。

### `POST /api/models/:provider/test`

使用真实适配器发送最小连接测试。成功返回实际供应商、模型、协议和耗时；云端错误返回 `MODEL_CONNECTION_FAILED`，不会伪造成功。

### `POST /api/chat/stream`

请求可携带 `provider` 和 `model`。服务端校验后保存到当前会话，并在 SSE `meta`、`done` 事件中返回实际选择。

## 前端互动

- 顶部选择器切换当前会话的供应商和模型。
- 设置面板展示每个供应商的适用场景、推荐模型和配置状态。
- 未配置供应商可以查看说明，但不能选择或测试。
- 已配置供应商可以执行真实连接测试。
- 流式生成期间禁止切换模型。
- 移动端设置面板以底部面板形式展示，避免遮挡输入区。

## 环境变量

```text
MODEL_PROVIDER=mock
MODEL_<PROVIDER>_API_KEY=server-only-secret
MODEL_<PROVIDER>_NAME=provider-model-name
MODEL_<PROVIDER>_API_URL=optional-endpoint-override
MODEL_TIMEOUT_MS=30000
```

存储配置：本地默认 `STORAGE_PROVIDER=json`。部署 PostgreSQL/Supabase 时设置 `STORAGE_PROVIDER=postgres`、`DATABASE_URL`，托管数据库通常还需要 `DATABASE_SSL=true`。当前 PostgreSQL 通道保存现有聚合状态，尚未完成多用户规范化表迁移。

当前适配族：OpenAI-compatible、Anthropic Claude、Google Gemini；目录包含 OpenAI、DeepSeek、通义千问、智谱 GLM、Kimi、MiniMax、SiliconFlow、Claude、Gemini 和本地 Mock。

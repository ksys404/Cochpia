# 产品基础架构蓝图

```text
客户端层
  自制前端 / Claude.ai Connector / 手机端 / PWA
        │
        ▼
应用编排层
  会话 API / 模型路由 / 上下文组装 / 统一 SSE / 调度器
        │                         │
        │                         ├── 主模型：生成当前回复
        │                         └── 辅助模型：摘要、观察、渲染
        ▼
独立记忆服务
  MCP / breath / hold / dream / grow / trace
        │
        ├── 事实与事件记忆
        ├── 关系与情绪记忆
        ├── 来源、权限、有效期和衰减
        └── 共享存储与跨端访问
        │
        ▼

  欲望账本 / 人格文件 / 证据卡 / 年轮存档 / 投影记账
        │
        ▼
治理层
  同意 / 审计 / 删除 / 导出 / 回滚 / 降级 / 成本 / 安全
```

## 设计原则

1. 前端只依赖自有协议，不直接依赖某一家模型 API 的流格式。
2. 记忆服务独立于任何一个客户端，客户端只是有权限的连接者。
3. 必须执行的机械流程由后端执行，需要判断的记忆和人格决策留给 AI。
4. 自动生成的内容必须有来源；没有证据宁可漏记，不可编造。
5. 记忆服务不可用时，聊天仍能降级运行。
6. 人格文件不允许自动无限增长，每次修改都保留历史版本。
7. 所有主动行为和人格变化都应可见、可关闭、可撤销。

## 最近修复的问题

曾出现：

```text
Cannot read properties of null (reading '0')
```

原因是后端旧进程没有新路由 `/api/personality/history`，未知 API 路径又错误回退为 `index.html`。当前已修复：

- 重启后端加载新路由
- 未知 `/api/*` 返回 404 JSON
- 前端增加空数组和空响应防护

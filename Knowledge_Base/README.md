# Cody Knowledge Base

这是 Cody 的本地知识库。第一批资料聚焦于长期记忆、时间知识图谱、情绪连续性、AI 陪伴与智能体自我演化。

## 目录

- `原始资料/pdf/`：原始 PDF 文件。
- `原始资料/图片/`：原始图片文件。本批次暂为空。
- `原始资料/网页/`：下载的网页 HTML 与原始 README。
- `分析报告/`：摘要、比较分析和抽取文本。
- `标签索引/`：来源、标签、处理状态和文件映射。

## 处理流程

1. 保存原始文件，不覆盖、不改写。
2. 提取网页或 PDF 文本。
3. 对图片资料执行 OCR；没有图片时记录为空，不生成虚假文字。
4. 建立摘要，区分来源陈述与 Cody 的分析判断。
5. 保存标签索引、来源 URL、文件路径和处理状态。

## 当前批次

当前批次包含 EverOS、Utsuwa、Graphiti、ZifaMem，以及 CTEM 论文。ACM DOI 页面存在访问限制，论文原始文件使用其公开 arXiv 对应版本 `2605.15812` 保存；DOI 和 arXiv 来源均记录在索引中。

## 证据约定

- `原始资料` 是来源文件，不代表其中全部主张已经被独立验证。
- `分析报告` 是基于原始资料的归纳和研究判断。
- 工程仓库 README 的性能、效果和路线图属于项目方陈述，应通过代码、实验和独立复现实验进一步验证。

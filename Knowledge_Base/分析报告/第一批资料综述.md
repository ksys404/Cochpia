# 第一批资料综述：长期记忆与陪伴型智能体

## 结论摘要

五项资料共同指向一个方向：AI 不应只是检索对话片段，而应维护可验证、可更新、可解释、可撤销的长期认知状态。该状态至少包括事件、事实、关系、情绪、技能、偏好和证据来源。

统一闭环可以表示为：

`交互捕获 -> 记忆提取 -> 多层表示 -> 时间更新 -> 任务相关召回 -> 响应 -> 用户反馈 -> 反思与修正`

## 资料归纳

### EverOS

EverOS 将 Markdown 作为可读、可编辑、可 diff 和可 Git 版本控制的事实源，再使用 SQLite 与 LanceDB 做本地检索。其重点是跨应用、跨代理、用户拥有和离线优先，并提出对 episode、profile、case、skill 进行分层以及离线 reflection。研究价值在于把记忆从后端数据库重新带回用户可检查的文件系统。风险是 Markdown 与索引、并发写入、权限和事实冲突之间仍需要更严格的一致性协议。

### Graphiti

Graphiti 以 episode、entity、fact/relationship 和 ontology 构建实时上下文图。事实拥有有效时间窗口，旧事实可以失效但不被删除；关系可以追溯到原始 episode；检索结合语义、关键词和图遍历。研究价值在于解决动态世界中的时间、溯源和多跳关系问题。需要进一步验证的是冲突判定、图规模成本、LLM 抽取错误传播和恶意关系注入风险。

### ZifaMem

ZifaMem 将记忆生命周期建模为创建、强化、弱化、合并、反思、遗忘，并加入情绪、信任、舒适、冲突、脆弱性、依恋和边界等信号。其 alpha SDK 采用会话缓冲、会话摘要、长期记忆和用户画像四层结构。它把“记住了什么”扩展为“这件事为何重要以及如何影响关系”。目前自动合并、反思循环、用户审核、生产存储和长期评估仍未完成。

### Utsuwa

Utsuwa 将语义记忆、关系阶段、动态情绪、3D VRM 角色、语音、动作和本地 IndexedDB 结合为可交互的 AI 陪伴产品。它证明记忆可以成为用户可感知的交互体验，而不只是后台 RAG。研究重点应放在关系阶段是否真的改善长期体验，以及视觉拟人、情感反馈和记忆控制之间的伦理边界。

### CTEM 论文

CTEM 将长期行为历史、即时情感状态、当前行为和用户反馈组成闭环，并以 Auri 进行 21 天真实环境研究。其核心不是给每条消息附加情绪标签，而是让过去行为更新内部状态，再由内部状态影响后续表达。论文摘要报告自然度、一致性和情绪协调性改善；复现时应重点检查研究样本、基线、情绪状态更新规则和长期副作用。

## 共同架构

1. 事件层：保留原始交互和来源。
2. 语义层：抽取事实、偏好、任务和技能。
3. 关系层：保存实体关系及时间有效区间。
4. 情绪层：保存触发、强度、持续时间、支持偏好和修复结果。
5. 画像层：形成可解释的稳定用户模型。
6. 治理层：同意、权限、审核、回滚、删除和遗忘。
7. 评估层：测量准确性、召回、遗忘、冲突、负迁移和安全性。

## 关键研究缺口

- 记忆重要性应由未来决策价值，而不只是重复次数决定。
- 事实、愿望、假设、玩笑和角色扮演必须分离。
- 每条高影响记忆都应保存来源、置信度、最后验证时间和修改历史。
- 情绪强烈不等于事实可靠，情绪层和事实层必须解耦。
- 自我进化应经过候选规则、历史验证、小范围启用、观测和回滚。
- 长期记忆需要专门的投毒、越权召回、隐私泄露和隐藏触发测试。

## 可继续研究的方向

- 记忆编译器：把经验编译成事实、规则和技能。
- 因果记忆：记录事件及其结果，而非只有相似文本。
- 主动记忆获取：智能体判断何时询问用户以降低不确定性。
- 记忆不确定性：允许系统明确表达不知道和暂不采用。
- 多代理共享记忆：区分公共、个人和代理私有知识。
- 记忆回滚与时间旅行：恢复某一时点的认知状态。
- 记忆压缩：以最低 token 成本保留最高决策价值。
- 认知债务：识别过时、矛盾和未经验证记忆对系统的累积影响。
- 可解释召回：向用户展示某次回答使用了哪些记忆。
- 长期评估：同时测量适应性、稳定性、遗忘、泛化和负迁移。

## 判断边界

EverOS、Graphiti、Utsuwa 和 ZifaMem 的 README 主要是项目方自述；CTEM 的效果来自论文报告。以上资料适合作为研究入口，不应直接视为已经独立复现的结论。
